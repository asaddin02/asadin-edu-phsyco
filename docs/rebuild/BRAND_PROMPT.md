# Logo Asadin Edu Physics

Mode: built-in `image_gen` tool melalui skill imagegen; bukan CLI/API fallback. Dibuat 26 September 2026 dan disalin ke `assets/brand/logo-ai.png`. PNG RGBA 1254 × 1254; transparansi asli dipertahankan. Dipakai di navbar, footer, favicon dan manifest. Aset SVG lama tetap tersedia sebagai riwayat.

Konsep terpilih: buku terbuka merah, lintasan orbit, dan percikan amber. Wordmark dirender sebagai teks HTML sehingga tetap tajam dan dapat diakses. Prompt awal menyebut anak-anak; pengguna kemudian memperjelas rentang SD–pengajar. Simbol buku dan orbit dipertahankan untuk semua jenjang; bahasa, jalur dan tampilan aplikasi disesuaikan untuk rentang tersebut.

Prompt final yang dikirim:

> Use case: logo-brand. Create one polished app logo icon for ASADIN EDU PHYSICS, an Indonesian physics learning app for children. Brand symbol only, absolutely no text. A simple distinctive rounded open-book silhouette whose pages curve into one graceful physics orbit around a small warm orange sun/spark, conveying curiosity, learning and motion. Primary vermilion red #E5483B with small warm amber accent, white negative space. Friendly, intelligent, clean flat vector-like silhouette, thick consistent shapes, legible at 32px, not a complex atom diagram. Centered square composition, icon fills about 80 percent. True transparent background. No gradients, no shadows, no mockup, no border, no lettering, no watermark. Deliver a single finished logo asset.

Hasil dipilih setelah inspeksi visual; dipakai sebagai PNG asli tanpa penyuntingan raster tambahan. Aksen UI memakai merah lebih gelap #bd382c agar teks kecil memenuhi pemeriksaan kontras pada latar terang.
